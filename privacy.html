Política de Privacidade — Clips Auto Live

Última atualização: 18 de novembro de 2026

1. Resumo

O Clips Auto Live roda no computador do próprio criador e é usado somente nas contas dele. Ele não tem servidor próprio e não vende, não compartilha e não coleta dados de outras pessoas.

2. Dados usados

  • Gravações das lives do criador: ficam no computador dele e são usadas para gerar os cortes.
  • Tokens de acesso (TikTok, Instagram, YouTube): guardados só no computador do criador, para publicar nas contas dele.
  • Dados básicos da conta do TikTok (escopo user.info.basic: nome de exibição e identificador): usados só para mostrar qual conta está conectada.

3. Para que

Os dados servem só para publicar os vídeos do criador nas contas dele (escopo video.publish) e conferir o status das publicações.

4. Compartilhamento

Os vídeos são enviados apenas para as plataformas que o próprio criador autorizou. Para gerar títulos e legendas, trechos de transcrição e quadros das lives do criador podem ser processados pelo serviço de IA da Anthropic (Claude), que o criador usa com a conta dele. Nenhum dado é vendido nem usado para publicidade.

YouTube API Services

O Clips Auto Live usa os YouTube API Services para enviar vídeos ao canal do próprio criador. Ao usar o app, o criador também concorda com os Termos de Serviço do YouTube e com a Política de Privacidade do Google.

Dados do YouTube acessados: identificação e nome do canal (channels.list), playlists do canal (para organizar os episódios) e os vídeos que o próprio app envia. Nada disso sai do computador do criador, exceto o envio para o próprio YouTube.

Como revogar e apagar: o acesso pode ser revogado a qualquer momento em https://security.google.com/settings/security/permissions. Depois de revogado, o token guardado no computador deixa de funcionar; ele e os demais dados locais são apagados ao excluir a pasta credenciais/ ou a pasta do app. Dados obtidos da API do YouTube não são guardados por mais de 30 dias.

5. Guarda e exclusão

Tudo fica no computador do criador. Para apagar, basta desconectar a conta no aplicativo (ou revogar o acesso nas configurações da plataforma) e excluir a pasta do aplicativo.

Privacy Policy — Clips Auto Live

Clips Auto Live runs on the creator's own computer and is used only with the creator's own accounts. It has no server and does not collect, sell or share data about other people. It uses the creator's live-stream recordings (stored locally) to make clips; access tokens for TikTok, Instagram and YouTube (stored locally) to publish to the creator's own accounts; and basic TikTok profile info (user.info.basic) only to show which account is connected. Videos are sent only to the platforms the creator authorized (video.publish). Transcript excerpts and frames from the creator's own streams may be processed by Anthropic's Claude AI to write titles and captions. To delete everything, disconnect the account (or revoke access in the platform settings) and delete the app folder. This app uses YouTube API Services to upload videos to the creator's own channel. By using it, the creator also agrees to the YouTube Terms of Service; see also the Google Privacy Policy. YouTube data accessed: channel id/name (channels.list), the channel's playlists and the videos this app uploads; it stays on the creator's computer and is not kept for more than 30 days. Revoke access anytime at https://security.google.com/settings/security/permissions; after revocation the stored token stops working, and it is deleted together with all local data by deleting the app folder.
